# Personal Portfolio Site

My personal development portfolio. This started as a school assessment, but I kept going and expanding the scope because it turned into a
fun project.

**Live:** [owhitedevportfolio.ddns.net](http://owhitedevportfolio.ddns.net)

## What's in it

- Light/dark/system theme switcher (Catppuccin + OKLCH)
- Blog and project pages, auto-built from JSON so I'm not hand-coding cards
- Pill-based tag filtering
- An image carousel on the About page
- A live GitHub commit tracker
- A GitHub contribution graph clone
- A Hackatime coding-time dashboard
- Actually responsive now (it wasn't for a while)

The contribution graph and Hackatime dashboard run on scheduled GitHub Actions rather than
live client-side calls, since both need credentials that can't safely sit in browser JS.
